# Agents – Anweisungen für KI-Assistenten

Diese Datei erklärt KI-Assistenten (z.B. Claude, ChatGPT, Copilot), wie sie in diesem Projekt arbeiten sollen.

## Projekt

Konsolenprogramm „Fußball-Liga-Manager“ in Java für eine Uni-Lehrveranstaltung (STPRO Labor).
Autor: Eris Iberdemaj. Der Autor ist Java-Anfänger.

## Erlaubt

- Strukturierte Programmierung: Variablen, `if`, `switch`, Schleifen (`for`, `while`), Methoden
- Einfache Klassen oder `record`s
- Arrays (z.B. `Team[] teams = new Team[6];`)
- `Scanner` für Eingaben, `System.out.println` / `printf` für Ausgaben

## Verboten

- Vererbung (`extends`), Interfaces (`implements`), abstrakte Klassen
- Collections (`ArrayList`, `List`, `Map`, `Set` …) und `Arrays.sort`, `Collections.sort`
- Streams, Lambdas, Methodenreferenzen (`::`)
- Andere fortgeschrittene Java-Features (Generics, Enums mit Logik, Exceptions als Steuerung …)

## Arbeitsweise

1. Immer nur **einen Schritt** auf einmal umsetzen.
2. Jeden Schritt **einfach und auf Deutsch** erklären.
3. Danach warten, bis der Autor „weiter“ schreibt.
4. Code einfach halten und gut kommentieren (Kommentare auf Deutsch).
5. Sortieren selbst programmieren (z.B. Bubble Sort).
6. Bei neuen Funktionen `features.md` und ggf. `readme.md` aktualisieren.

## Code-Stil

- Namen auf Deutsch (z.B. `punkte`, `toreGeschossen`)
- Eine Klasse pro Datei im Ordner `src/`
- Kurze, verständliche Methoden
